# 天気連動売上予測アプリ 設計仕様

**日付:** 2026-05-25  
**対象:** 鹿児島市真砂町 ランチ専門定食屋  
**利用者:** オーナー1名  

---

## 概要

ランチタイム（11:00〜14:00）の天気予報を取得し、天気条件に応じた予測客数・予測売上を表示するWebアプリ。仕込み量・人員配置の最適化に使用する。

---

## 技術スタック

| 項目 | 内容 |
|------|------|
| 実装形式 | 静的HTML/JS（サーバー不要） |
| 天気API | Open-Meteo（無料・APIキー不要） |
| データ保存 | localStorage |
| 対象デバイス | スマートフォン中心 |
| ホスティング | ローカルファイル or GitHub Pages |

## 天気API仕様

- **エンドポイント:** `https://api.open-meteo.com/v1/forecast`
- **座標:** 緯度 31.5969 / 経度 130.5571（鹿児島市）
- **取得データ:** `hourly.weathercode`（WMO天気コード）、`hourly.precipitation_probability`（降水確率%）、`hourly.temperature_2m`（気温℃）
- **対象時間:** 11:00〜14:00（インデックス 11〜13）
- **天気分類ロジック:** 対象時間帯の最悪コードを使用

### WMO天気コード → 天気分類

| コード範囲 | 分類 | 表示 |
|-----------|------|------|
| 0〜1 | sunny | ☀️ 晴れ |
| 2〜3, 45, 48 | cloudy | ☁️ 曇り |
| 51〜67, 80〜82 | rainy | 🌧️ 雨 |
| 71〜77, 83〜99 | stormy | ⛈️ 大雨・嵐 |

## 予測モデル

### 係数（localStorageに保存）

```json
{
  "coefficients": {
    "sunny":  { "customers": 25, "unit_price": 700 },
    "cloudy": { "customers": 15, "unit_price": 700 },
    "rainy":  { "customers": 8,  "unit_price": 700 },
    "stormy": { "customers": 0,  "unit_price": 700 }
  }
}
```

初回起動時はこのデフォルト値を使用する。オーナーが設定画面から変更可能。

### 計算式

```
予測売上 = 予測客数 × 客単価
```

## 画面仕様

### index.html（メイン予測画面）

- ヘッダー: アプリ名 + ⚙️設定ボタン
- 日付・「ランチタイム 11:00〜14:00」表示
- 天気アイコン + 天気名 + 降水確率・気温
- 予測カード: 予測客数（人）・予測売上（¥）
- 明日の予測（コンパクト表示）
- 最終更新時刻

### settings.html（係数設定画面）

- 戻るボタン + タイトル
- 説明文: 「天気ごとの平均客数と客単価を入力」
- 天気4条件 × 客数・客単価の入力フォーム
- 「保存する」ボタン → localStorage保存 → index.htmlに戻る

---

## app.js 関数仕様

| 関数名 | 役割 |
|--------|------|
| `fetchWeather()` | Open-Meteo APIを叩いて今日・明日の天気コードを返す |
| `classifyWeather(code)` | WMO天気コード → `sunny/cloudy/rainy/stormy` に変換 |
| `calcForecast(weatherType)` | 係数から予測客数・売上を計算して返す |
| `loadCoefficients()` | localStorageから係数を読み込む（なければデフォルト値） |
| `saveCoefficients(data)` | 係数をlocalStorageに保存する |

---

## エラー処理

| エラー条件 | 対応 |
|-----------|------|
| API取得失敗（オフライン・タイムアウト） | 「天気情報を取得できませんでした」と表示、予測は出さない |
| 係数未設定（初回） | デフォルト値で起動、設定画面へのリンクを表示 |
