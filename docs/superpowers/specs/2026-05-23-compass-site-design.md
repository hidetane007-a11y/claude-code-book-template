# コンパス社 ビジネスサイト 設計仕様

**作成日**：2026-05-23  
**ステータス**：承認済み

---

## 概要

コンパス社（AI Business Consultant）のリード獲得特化型ランディングページ。
国内中小企業・スタートアップをターゲットに、問い合わせ（LINE＋フォーム）への
コンバージョンを最大化する1ページ完結型サイト。

---

## 要件

| 項目 | 内容 |
|---|---|
| ターゲット | 国内中小企業・スタートアップ |
| 主な目的 | リード獲得（問い合わせ・商談獲得） |
| 問い合わせ | LINE公式アカウント ＋ Formspreeメールフォーム |
| デザイン | 先進的・AI感（黒×青紫グラデーション、テック寄り） |
| コンテンツ | ゼロから制作 |

---

## アーキテクチャ

### 技術スタック

| 項目 | 選択 |
|---|---|
| 構成 | 静的HTML / CSS / JavaScript |
| フォント | Google Fonts（Noto Sans JP） |
| アイコン | Font Awesome or SVG自作 |
| フォーム | Formspree（無料・サーバー不要） |
| LINE連携 | LINE公式アカウントURLボタン |
| ホスティング | リポジトリ内 `compass/index.html` |

```
│   └── style.css
├── js/
│   └── main.js

    └── profile.jpg
```

## セクション設計

### 1. HERO
- キャッチコピー：「AIで、経営の羅針盤を。」
- サブコピー：「地元金融機関で地域課題解決に10数年携わった経験と AI活用の知見で、創業・海外展開・AI活用をワンストップで支援します。」
- CTA：「LINEで無料相談する →」ボタン

### 2. PAIN（課題提起）
見出し：「こんな悩みを抱えていませんか？」

カード4枚：
1. 創業の手続きや資金調達、何から始めればいいか分からない
2. 海外に売りたいが、どの国・どのルートが正解か見えない
3. AIを使いたいが、自社のどの業務に活かせるか分からない
4. 専門家に相談したいが、費用対効果が読めず踏み出せない

### 3. SERVICE（3本柱）
3カラムカード構成：

| サービス | 説明 |
|---|---|
| 創業支援 | 事業計画・資金調達・行政手続きまで、リスクを見極めながら伴走 |
| 海外販路開拓 | 市場選定から現地パートナー探しまで最短ルートを設計 |
| AI活用コンサルティング | 業務効率化・営業強化・意思決定支援、導入設計から実装まで |

### 4. NUMBERS（実績数字）
3つの数字を大きく表示（実際の数値に差し替え）：
- 支援企業数 50+
- 海外案件数 30+
- 顧客継続率 95%

### 5. PROFILE（代表プロフィール）
写真左・テキスト右のレイアウト：

> 地元金融機関の地域課題解決部門で10数年、地域の中小企業・起業家と向き合い続けてきました。
> 資金・販路・人材——地域が抱えるリアルな課題を現場で見てきた経験と、AI活用の知見を掛け合わせ、
> 「次の一手」を共に考えるコンサルタントとして独立しました。
> 地域から世界へ。コンパスは、あなたのビジネスの進むべき方向を示す羅針盤でありたいと思っています。

### 6. CTA（問い合わせ）
- 見出し：「まずは無料でご相談ください」
- サブ：「LINEで気軽に質問するだけでも構いません。」
- ボタン2つ：「LINE公式で相談する」「メールフォームへ」
